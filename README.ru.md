# NexusBridge

**Независимый self-hosted мост между ИИ-чатом и компьютером владельца через MCP.**

[English](README.md) · [Дорожная карта](docs/ROADMAP.md) · [Безопасность](SECURITY.md)

Текущая версия — **0.1.0-alpha.5**. Это локальная тестовая среда для Windows 11 x64, не production-релиз. В отдельном ограниченном испытании подтверждена интеграция с обычным ChatGPT Desktop на аккаунте владельца. Поддержка других аккаунтов, web и mobile пока не гарантируется.

### Возможности

- 25 MCP-инструментов при явном включении тестовой записи и запуска процессов; 11 инструментов только чтения по умолчанию.
- Файловые операции, поиск, бинарные данные, SHA-256, резервные копии, точечные патчи, перемещение, корзина и восстановление.
- Запуск только заранее заданного тестового процесса, ограниченный ввод/вывод, Windows Job Objects, отмена дочерних процессов и тайм-аут.
- Локальный журнал операций с проверкой целостности и ограничением размера.

### Проверка

Установите Node.js 24.x и Git. Запускайте без прав администратора:

```powershell
git clone https://github.com/KamenevVA/NexusBridge.git
cd NexusBridge
npm ci --ignore-scripts
npm run typecheck
npm test
```

Для запуска MCP-сервера в режиме чтения: `node src/mvp-stdio.ts`. Не публикуйте его через туннель. Постоянный relay, GUI, полноценная изоляция Windows и произвольный терминал ещё не реализованы.

Публичный репозиторий не содержит частных журналов, конфигураций владельца и истории внутренних испытаний. Лицензия пока не утверждена.

Критические операции требуют точного одноразового локального подтверждения. Есть аварийная остановка и экспериментальный профиль отдельной непривилегированной учётной записи. Сетевая изоляция ещё не подтверждена; это не production-релиз.
